# Group-project-193DD, Hydrology/Water Quality

## General information

This repository contains data and code to explore the question of "How does precipitation explain salinity?" at North Campus Open Space. 

To work with the code in this repository, you will need the following packages:

```
library(tidyverse)
library(janitor)
library(here)
library(hrbrthemes)
library(viridis)
library(cowplot)
library(ggridges)
library(ggplot2)
library(NatParksPalettes)
library(wesanderson)
library(patchwork)
```
